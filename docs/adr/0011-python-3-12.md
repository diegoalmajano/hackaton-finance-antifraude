# ADR-0011: Python 3.12 para el proyecto

**Fecha**: 2026-11-08
**Estado**: accepted (D-26, D-27) — **instalación pendiente de autorización**
**Decisores**: usuario · Claude Code (propuesta)

## Contexto
La máquina tiene Python 3.14, muy reciente; algunas dependencias con extensiones nativas (p. ej. pythonnet, usado por pywebview en Windows) pueden no soportarlo (V-12).

## Decisión
El proyecto usa **Python 3.12** (versión de parche exacta a fijar al instalar), en un entorno virtual propio (ADR-0014). El README indicará la versión requerida.

## Alternativas consideradas
### Python 3.14 (ya instalado)
- **Por qué no**: riesgo de incompatibilidad con dependencias nativas.
### Python 3.13
- **Pros**: más reciente. **Por qué no**: 3.12 ofrece la compatibilidad más amplia.

## Consecuencias
### Positivas
- Menor riesgo de dependencias sin ruedas precompiladas.
### Negativas
- Instalar una segunda versión de Python en la máquina (requiere autorización).
### Riesgos
- Confusión entre versiones → usar siempre el launcher `py -3.12` y el venv del proyecto.

## Pendiente de verificar (⏳)
- Compatibilidad real de pythonnet/pywebview con 3.12 (V-12), al llegar a la fase g.
